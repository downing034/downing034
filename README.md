## Featured project: Paragon Sports Intelligence

[paragon-sports-intelligence.com](https://www.paragon-sports-intelligence.com) is an AI-powered sports prediction platform that publishes data-driven predictions, edge analysis, and confidence scores. The source is private because the prediction models are proprietary, so here's an overview of how it's built.

**Architecture**

- **Backend:** Ruby on Rails with a REST API and ActiveRecord
- **Frontend:** React and TypeScript, rendered through Inertia.js
- **Prediction models:** Python, with AI-assisted data research
- **Hosting:** Heroku

**Models**

| Sport | What it predicts | Status |
| --- | --- | --- |
| NCAA men's basketball | Game scores and winners (~80% accuracy picking winners, ~7-point mean absolute error) | Live |
| MLB | Game scores and starting pitchers | Built |
| NFL | Game scores and player props | Built, not yet released |

**Engineering practices**

- CI runs the RSpec and React Testing Library suites plus RuboCop and Prettier checks on every change
- Built with AI coding agents (Claude Code, OpenAI Codex) as a one-person team
